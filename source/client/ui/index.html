        手动修改接口

        游戏更新后，可在这里查看脚本实际使用的接口和兼容配置、尝试重新获取，或粘贴核实后的内容。接口包括原生模块符号、方法或字段映射、公开资源地址，并不全是网址。输入内容不会作为代码执行。

        使用教程 · 第一次使用按这几步操作
        1. 先查看每项名称前的状态和下面的原因。有效项通常无需修改；一个接口异常只影响需要它的功能，不能把“有输入值”当作“接口有效”。
        2. 点击异常项目右侧的自动获取，或下方的“自动获取本页全部”，让客户端按当前游戏公开资料与当前页面重新查找。成功的项目会恢复自动跟随，以后继续按新页面重新解析，不把这次获取值固定为旧版本地址；找不到的项目保留原配置与原因。等待完成后，核对配置方式、实际生效值和状态。
        3. 仍找不到时，点击一键获取提示词，复制给能够访问游戏官网的 AI。提示词包含游戏官网、当前公开模块线索和所需数据格式；无需发送本脚本、账号密码、Cookie、游客存档或个人配置。AI 不能联网或无法核实时，应明确说明，不能编造接口。
        4. AI 返回的是字段名或映射时，按对应项目粘贴到输入框；返回批量 JSON 时，在下方“批量导入/导出”粘贴。只粘贴配置数据，不粘贴 JavaScript 或可执行代码。点击保存并应用或导入后，写入的项目采用手动固定，游戏更新时也保留你指定的内容；需要恢复自动解析时，再点击“自动获取”或“恢复本页自动配置”。未应用的文字不会代替当前有效配置。
        5. 若显示“等待生效”，表示已保存但当前页面尚未采用；以实际生效值为准，保持当前对局，等待安全采用或按界面说明操作。无效修改会显示原因，并保留原有效配置。
        6. 接口配置正确后功能仍异常，请点上方手动修改其他配置，核对选择器、状态标识和其他已支持的兼容项。只读项展示来源和限制；填写数值不能创造游戏未开放的能力。
        7. 改错时，可先导出全部兼容配置留作备份，再用“恢复本页自动配置”。这些修复配置只保存在当前客户端文件夹，不上传给作者或 AI；具体游戏功能仍受原生资格和当前可用能力约束。
